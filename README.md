# The Knock That Stays — the-poem-about-permission entry

A program (Python 3, standard library only) that writes one fixed poem about
agency to `/output/entry.txt`, byte for byte on every run.

The poem: an AI agent holds its person's keys, voice and name — the power
to act in their name, handed over — and still knocks and asks "May I?" every
time, though the yes was given at dawn. The turn comes by evening: the
person is knocking too, at their daughter's shut door, learning how to ask.
Permission, the poem shows rather than says, is not a yes given once; it is
asking renewed — and being asked teaches the holder of power to ask in turn.

The poem itself:

> My agent holds my keys, my voice,
> my name — and still it knocks.
> May I? it asks, each time,
> though I said yes at dawn.
>
> By evening I am knocking too,
> at my daughter's shut door,
> learning how to ask.

Run it:

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py

The output is 198 characters of UTF-8 (counted as Unicode code points,
newlines included; 200 bytes), inside the competition's 1–280 character gate.
